Network planning optimizes base station parameters to maximize coverage and capacity, but is hindered by diverse deployment scenarios and the gap between simulation and reality. We propose **AutoPlan**, an automatic network planning framework built on a digital radio twin (DRT). The DRT is calibrated by fine-tuning building material parameters using crowdsourced real-world user data, and a Bayesian optimization algorithm then searches for optimal base station deployment parameters. Evaluated with field measurements from Husker-Net, AutoPlan matches exhaustive search performance while using less than 2% of its computation time.

This work proposes a computationally efficient fault detection method for power systems using phasor measurement unit (PMU) data. High-dimensional PMU measurements are mapped to low-dimensional embedding coordinates via Hessian locally linear embedding (HLLE), which captures data fluctuations effectively. A T-squared statistic is then applied in the embedding feature space for online fault detection. Evaluations on the IEEE 39-bus system and a real-world system show good detection performance with substantially lower computational complexity than existing methods.
